Interactive Brokers does not publish the Java TWS API on Maven Central.

1. Download the TWS API from https://interactivebrokers.github.io/ (Java).
2. Locate TwsApi.jar (often under the extracted API tree, e.g. source/JavaClient/ or samples/Java).
3. Copy that file here and rename it to exactly:

   tws-api.jar

This path is required for Maven: lib/tws-api.jar (repo root).
